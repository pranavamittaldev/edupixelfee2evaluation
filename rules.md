# Student Profile Management System

## Development Guidelines

This project should be kept simple, lightweight, and easy to understand.

### Technology Requirements

* Use **basic HTML and CSS** as the primary technologies.
* JavaScript **may be used when necessary**, but it is **not preferred**.
* Prefer HTML and CSS solutions whenever the requirement can be achieved without JavaScript.
* Do **not** introduce unnecessary frameworks or libraries.

### Do NOT Use

Unless explicitly requested, do not introduce:

* React
* Angular
* Vue
* Bootstrap
* Tailwind CSS
* jQuery
* TypeScript
* Frontend build frameworks
* Unnecessary external UI libraries

### Coding Philosophy

* Keep the code simple and beginner-friendly.
* Prefer straightforward HTML and CSS over complicated solutions.
* Avoid unnecessary abstractions.
* Avoid adding dependencies unless they are genuinely required.
* Reuse existing code and styles where possible instead of creating duplicate implementations.
* Do not rewrite or restructure unrelated parts of the project.
* Make the smallest changes necessary to complete a task.

### JavaScript Guidelines

JavaScript should only be used when HTML and CSS cannot reasonably provide the required functionality.

When JavaScript is necessary:

* Keep the JavaScript simple.
* Use vanilla JavaScript.
* Do not introduce JavaScript frameworks.
* Do not add unnecessary scripts or libraries.
* Keep JavaScript separate and organized rather than putting large amounts of code directly inside HTML.

### UI Guidelines

The interface should be:

* Clean
* Simple
* Responsive
* Student-friendly
* Easy to navigate
* Professional without being overly complicated

Use semantic HTML and maintain readable CSS.

### Important Instructions for AI Coding Agents

Before making changes:

1. Read and understand the existing project structure.
2. Check the existing HTML and CSS before creating new files or styles.
3. Follow the requirements in this README.
4. Do not introduce frameworks or unnecessary dependencies.
5. Do not modify unrelated functionality.
6. Prefer the simplest implementation that satisfies the requirement.
7. If JavaScript is not necessary, do not use it.

When completing a task, preserve the existing architecture and coding style unless explicitly instructed otherwise.
